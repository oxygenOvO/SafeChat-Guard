# SafeChat-Guard V1.0 Release Notes

正式产品名称：**SafeChat-Guard 大模型对话内容安全防护系统 V1.0**  
代码版本：`1.0.0`

## 正式入口与导航

Streamlit 唯一正式入口为 `frontend/streamlit_app.py`，该文件仅委托
`frontend.product_app.main`。九页导航顺序保持不变：安全对话、系统总览、
模型管理、安全策略、安全日志、风险统计、安全评测、系统状态、系统设置。

原 `frontend.phase2_app` 保留为兼容导入，仅转发 `main`。旧竞赛 UI 已归档到
`archive/legacy_frontend/`，不再属于正式入口或正式导航。

## 生产模型调用边界

生产调用链保持为：

`SafeChatPipeline → LLMAdapterFactory → BaseLLMAdapter → OpenAICompatibleAdapter → OpenAICompatibleLLMClient`

`LLMClientFactory` 仅作为已弃用的底层客户端兼容层保留，生产 Pipeline 与产品前端
均不使用它。Provider 仍为 Offline Mock、DashScope Qwen、NSCC-CS MaaS Qwen3.5
和 DeepSeek；endpoint、model、timeout 与 API Key 环境变量机制均未调整。

## 评测与数据最小化

安全评测六种模式、指标算法以及 production/evaluation 隔离均保持不变。
`EvaluationService.to_csv()` 默认不导出原始 `text`；只有调用方显式传入
`include_text=True` 才包含该列。
